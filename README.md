# Varde

Varde is one stylesheet: fonts, dark/light mode, styled native elements, and utilities for spacing, layout, typography, and color.

Docs: https://varde.variant.dev

## Set up

Link the stylesheet:

```html
<link
  rel="stylesheet"
  href="https://varde.variant.dev/v/<VERSION>/styles.css"
/>
```

Varde follows the user's system preference for light and dark. To force one, set it on `<html>`:

```html
<html lang="en" class="ink-default surface-base" data-color-scheme="dark" />
```

Everything else lives in the docs.
